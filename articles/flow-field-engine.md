你大概见过天气预报 App 里那种流动的风场：无数条纤细的流线掠过地图，仿佛空气真的在动。那种效果并不神秘——它只是一个 **流场（Flow Field）**，加上一堆追风的粒子。本文带你用最少的代码，从零实现一个极客版的风场，而且鼠标所到之处，会形成一个真正的"风眼"。

## 一、流场是什么

流场是一个函数：给定平面上任意一点 `(x, y)` 和时间 `t`，返回一个方向（角度）。粒子只是沿着这个方向前进。如果相邻区域的角度是**连续变化**的，画面就会呈现出平滑、流动的曲线；如果角度是随机的，就只是一团乱麻。

问题来了：怎么让角度连续变化？答案是一张**连续噪声图**。最常见的工具是 Perlin Noise 与 Simplex Noise。这里我们用 Simplex Noise，它在高维下更快、且没有明显的方向性伪影。

```js
// 2D Simplex Noise 的关键：把输入点映射到三角形网格
// 每个点由三个顶点做梯度插值，而非四角，
// 因此维度越高，开销反而越低（O(N) 而非 O(2^N)）。
const n = noise.noise2D(x * 0.0016, y * 0.0016 + t * 0.12);
return n * Math.PI * 4;   // 乘以 4π，让方向在 -2π ~ 2π 间缓慢扭转
```

注意那个 `t * 0.12`：把时间混进坐标，流场就会随时间"呼吸"，画面立刻活过来。

## 二、粒子只是信使

粒子本身不思考，它们只是把流场的角度变成位移：

```js
function update(p, t) {
  const ang = fieldAngle(p.x, p.y, t);
  p.x += Math.cos(ang) * p.speed;
  p.y += Math.sin(ang) * p.speed;
}
```

但直接更新 `(x, y)` 画一个点，看起来像灰尘。真正的"丝线感"来自**上一帧位置**：把上一帧和这一帧连成一条线段。速度越快，线段越长，视觉上就成了被风拉长的丝。这也是为什么天气预报的风场看起来像丝绸而不是烟花。

## 三、制造风眼

风眼（台风眼）在现实里是低压中心，空气围绕中心旋转。在代码里，我们给每个粒子叠加一个**旋涡力场**：以鼠标为中心，垂直方向加切向速度，让它绕圈；同时加一点点向心吸力，把粒子拉近。

```js
const dx = p.x - mouse.x, dy = p.y - mouse.y;
const d  = Math.hypot(dx, dy) || 1;
const fall = influence(d);            // 距离越远影响越小

const tx = -dy / d, ty = dx / d;      // 切向（绕鼠标旋转）
const ix =  dx / d, iy = dy / d;      // 径向（指向鼠标）

p.x += (tx * swirl - ix * inward) * p.speed * fall;
p.y += (ty * swirl - iy * inward) * p.speed * fall;
```

最妙的一步是**核心掏空**：当粒子离鼠标非常近时，给它一个反向的径向力把它推开。这样旋涡中心反而空出一小块"宁静区"——真正的台风眼，永远是最平静的地方。

## 四、性能要点

1. **不要每帧新建对象**，用对象池复用粒子。
2. **按设备像素比缩放画布**，但上限设为 2，防止 4K 屏被粒子数拖垮。
3. **离屏后暂停**：`document.hidden` 时停掉 `requestAnimationFrame`，回来后继续。
4. 移动端把粒子数砍到桌面端的 1/3，速度反而更顺。

```js
const count = width * height < 500_000 ? 80 : 220;
```
