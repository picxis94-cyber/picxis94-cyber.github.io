"暗黑风格"做不好，很容易变成"脏黑风格"：一片死黑，看不清边界，层次全无。深色设计有一套**反直觉**的规则，这篇把这些规则讲清楚。

## 一、纯黑是陷阱

`#000000` 是深色设计的头号陷阱。纯黑周围的一切都会被衬得更亮，而 OLED 屏幕上的纯黑与真正的"设计黑"之间，观感差异极大。正确的做法是给背景一个**极低的亮度**，并带一点色相：

```css
:root {
  --bg: #05080c;        /* 不是 #000，带一点点冷 */
  --bg-2: #080d14;      /* 高于背景的层级 */
  --panel: rgba(13, 20, 30, .55);
  --line: rgba(120, 200, 220, .14);  /* 隔断线也要有颜色 */
}
```

层级 = 亮度递进：背景最暗 → 面板稍亮 → 边框更亮。用户靠**亮度差**判断层级，而不是靠边框。

## 二、文字对比度：别让眼睛受苦

深色底上，纯白文字对比度过高，长时间阅读会刺眼。正文用 `#dbe7ef` 这类带冷色的浅灰，次要文字用更暗的灰，形成三级文字系统：

```css
--text: #dbe7ef;        /* 主内容 */
--text-dim: #8296a6;    /* 次要 */
--text-faint: #4d5f6e;  /* 弱化 / 装饰 */
```

> 规则：对比度至少 4.5:1（WCAG AA）。但"能达标"和"好看"之间，还有一个词叫克制。

## 三、阴影在深色里是加法，不是减法

浅色界面靠投影"浮起来"，深色界面投影几乎看不见，反而要用**内发光和边缘高光**。一个技巧：给卡片顶部加一条 1px 的微弱亮线，模拟光从上方落下：

```css
.panel {
  box-shadow: inset 0 1px 0 rgba(255, 255, 255, .04);
}
```

一条 4% 白的内高光，胜过十层黑投影。

## 四、高亮色：降低饱和度

同一种品牌色，浅色模式下很鲜艳，到了深色底上就会刺眼、发荧光。深色界面里的主色应该**降低饱和度、提高明度**，让它在暗底上"呼吸"而不"尖叫"：

```css
:root { --accent: #5eead4; }        /* 深色模式 */
[data-theme="light"] { --accent: #0d9488; }  /* 浅色模式再加深 */
```

同样的色相，两种模式两套值——这也是为什么好的设计系统会把颜色放进 CSS 变量，而不是写死。

## 五、别忘了动效和玻璃

深色界面天然适合 `backdrop-filter: blur()` 的毛玻璃，但**玻璃后面的内容会透出来**，糊成一片。所以玻璃只该出现在导航栏、浮层这些短暂停留的地方，正文区域保持不透。

最后一条心法：

> 暗黑不是主题，是舞台。灯光（高亮色）越少，舞台越高级。

把"暗黑"当成一种氛围而非目标，你的界面自然会高级起来——就像这个博客一样。
